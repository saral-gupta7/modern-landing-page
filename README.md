# Still Reverie

Still Reverie is a cinematic photography-inspired landing page built with Next.js, GSAP, and Tailwind CSS. It combines immersive scroll-driven transitions, layered editorial layouts, optimized media, and a mobile-friendly presentation to create a mood-led visual storytelling experience.

## Features

- Scroll-based hero, gallery, and section animations powered by GSAP
- Optimized image and video assets for faster loading
- Responsive layouts for desktop and mobile
- Minimal editorial styling with cinematic photography direction

## Getting Started

Run the development server:

```bash
pnpm dev
```

Build for production:

```bash
pnpm build
```

Start the production build locally:

```bash
pnpm start
```
